    常驻页面数量
    同时保留在后台的页面数量（0–5）。设为 0 时只保留当前页面；越多切换越快，内存占用也越高。
    启动时打开
    应用启动后默认显示的页面。
    固定侧边栏
    让收藏栏常驻显示，不再自动隐藏。
    快捷键
    ⌃Tab循环切换到下一个页面
    ⌃⇧Tab循环切换到上一个页面
    ⌘⇧Space页面总览（可搜索）
    ⌘1 ~ 9直接切换到第 N 个收藏
    ⌘L聚焦地址栏
    ⌘R刷新当前页面
    ⌘[⌘]后退 / 前进
    ⌘,打开设置
    ⌘W关闭设置，或隐藏窗口
    数据
    备份收藏
    导出为 JSON，或从备份文件导入（自动跳过重复网址）。
    清除网站数据
    清除所有收藏页面的 Cookie、登录状态与缓存。操作不可撤销。
